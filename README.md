# Smart Subtitles for Hulu

Bilingual AI subtitles for Hulu videos: the original English subtitles with a natural translation into one of 55 languages, shown over the player.

- **Terms of Use and Privacy Policy:** https://jinzhou5042x.github.io/smart-subtitles-for-hulu/
